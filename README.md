This program uses Core Java tools to simulate the consumption of weather data from a REST API. A JSON-formatted string is used as the input data, and the program parses this data using String manipulation methods such as split(). The extracted information is then formatted and displayed using System.out.println() statements. No external libraries or frameworks are used, which makes the program simple, lightweight, and suitable for beginners to understand basic REST API data handling.
